# Emsi Shot At

Telefonda ve bilgisayarda çalışan, 205 kartlık flörtöz içki kart oyunu.

**Oyna:** https://balcikponcik.github.io/emsishot/

- Tam ekran desteği (iPhone'da Safari → "Ana Ekrana Ekle")
